# 👗 Body Shape & Fashion Recommendation System

An AI-based women's body shape and fashion recommendation system using
**EfficientNet-B1** and PyTorch.

The system identifies body shape and provides fashion recommendations
based on the detected body type and selected clothing category.

## ✨ Features

- 🔍 Women's body shape classification
- 👗 Supports 5 body shapes:
  - Apple
  - Triangle
  - Inverted Triangle
  - Rectangle
  - Hourglass
- 🧠 EfficientNet-B1 deep learning model
- 🍎 Optimized for Mac using Apple MPS
- 👚 Supports multiple fashion categories
- 🖼️ Displays 4 fashion recommendations
- 💡 Provides body-shape-specific styling tips

The EfficientNet model uses a custom classifier with dropout,
batch normalization and fully connected layers.
